# Security / Sicherheit

Please report suspected vulnerabilities privately to **ai@aitomat.ai**, the email listed on the [official contact page](https://aitomat.ai/contact/). Do not disclose an unpatched vulnerability in a public issue.

Include the app version, macOS version, Mac architecture, expected impact and minimal reproduction steps using synthetic data. Please omit passwords, provider keys, recordings, private transcripts and customer information. No response-time commitment is made here.

Bitte melden Sie mögliche Sicherheitslücken vertraulich an **ai@aitomat.ai**, laut [Kontaktseite](https://aitomat.ai/de/kontakt/). Veröffentlichen Sie ungeklärte Sicherheitslücken nicht als Issue. Nennen Sie Version, macOS, Architektur, mögliche Auswirkungen und Schritte mit Beispieldaten. Bitte senden Sie keine Zugangsdaten, Schlüssel, privaten Aufnahmen, Transkripte oder Kundendaten.
