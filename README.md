# Aitomat Dictate Studio

Local dictation for macOS with optional AI post-processing using your own provider key. Your words appear where your cursor is. After downloading the speech model, local dictation works offline.

Includes history, clipboard history, snippets, screenshots, screen and webcam recording, meeting mode and a knowledge base. See [features](https://aitomat.ai/features/) and [pricing](https://aitomat.ai/pricing/) on the official website.

## Requirements

macOS 14 or later; Apple Silicon (M1 or newer) or Intel. Apple Silicon uses Nemotron by default, with Parakeet as an alternative; Intel uses Whisper.

## Privacy

Speech recognition runs locally. Optional cloud AI processing sends the selected text and included context directly to your chosen provider; its data rules apply. Provider keys are stored in macOS Keychain. See [privacy](https://aitomat.ai/privacy/).
